# LearnLab: Why Ice Floats

This directory is an independent prototype. It does not replace or modify either existing EDUFORGE workflow.

## Run it on GitHub

1. Open the repository's **Actions** tab.
2. Select **LearnLab — Why Ice Floats**.
3. Choose **Run workflow** on the default branch.
4. Download the `learnlab-why-ice-floats` artifact and review the MP4 before publishing.

The workflow runs only when manually dispatched. It uses Blender for a procedural 3D infographic, FFmpeg for assembly and validation, and Edge TTS for narration. No paid model API, external 3D assets, repository write permission, or account secret is required. The generated video is 720 × 1280 at 24 fps to keep this CPU-rendered prototype practical. The Actions artifact expires after seven days; download it if you want to retain it.

Edge TTS is an unofficial client of Microsoft's online speech service. Its free availability does not itself grant commercial-use rights. Before monetizing a video using this narration, verify the applicable service terms and your intended use. The seed records OpenStax Biology 2e as the science source. A person should still check the claims, caption timing, sound, safe margins, and rendered visuals before upload.

The output is intentionally an illustrative model, not a scientific simulation. The molecule arrangements and floating cube are explanatory visuals rather than scale-accurate representations.
