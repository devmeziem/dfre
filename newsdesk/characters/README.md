# Recurring presenters (saved characters)

These are **stable character definitions** for 9jaBeacon-style desk videos.
Reuse the same IDs every episode so the audience recognizes the faces.

| ID | Name | Role | Voice (Edge TTS) |
|----|------|------|------------------|
| `ada` | Ada Okoro | Lead evening presenter | `en-NG-EzinneNeural` |
| `femi` | Femi Adeyemi | Politics / national desk | `en-NG-AbeoNeural` |
| `tunde` | Tunde Balogun | Sports & world wire | `en-GB-RyanNeural` |

Files: `ada.json`, `femi.json`, `tunde.json`.

Blender scripts read `skin`, `outfit`, `voice`, and `default_pose` from these files.
