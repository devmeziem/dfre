# Presentation environments (5)

| ID | Name | Use |
|----|------|-----|
| `studio_main` | Main evening desk | Default national bulletin |
| `studio_breaking` | Breaking news | Red lighting, urgency |
| `studio_world` | World affairs | Cooler palette |
| `studio_sports` | Sports desk | Warmer accent |
| `studio_economy` | Markets / hustle | Teal accent |

Each environment defines wall colors, desk style, board count, and ticker style.
Boards can show article stills + headlines inside the 3D scene.
